Variables y parámetros del modelo

Variables de entrada

Las variables de entrada determinan cómo llegan los clientes y cuánto tiempo utilizan el servicio.

Nombre Descripción Tipo Unidad Fuente Distribución utilizada Parámetros
Tiempo entre llegadas Tiempo transcurrido entre la llegada de dos clientes consecutivos. Cuantitativa continua. Segundos. BeginDateTime del dataset POS, calculando diferencias entre llegadas consecutivas. Empírica; exponencial como candidata por evaluar. Empírica: frecuencias de los intervalos observados. Exponencial: λ = 1/t̄, donde t̄ es el intervalo medio estimado.
Tiempo de atención Tiempo que utiliza el cajero para procesar una transacción. Cuantitativa continua en el modelo; registrada en segundos enteros. Segundos. Variable TranTime del dataset POS. Empírica. Lognormal como alternativa por contrastar. Media preliminar: 73,70 s; desviación estándar: 64,35 s. La lognormal no se considera validada.
Cantidad de productos Número de artículos que lleva cada cliente. Cuantitativa discreta. Artículos por cliente. Variable ArtNum del dataset POS. Empírica discreta. Media preliminar: 14,34; desviación estándar: 14,90; mínimo: 1; máximo: 221.
Número de clientes Cantidad de clientes que ingresan durante el horizonte de simulación. Cuantitativa discreta. Clientes. Derivada de los registros de llegada del dataset y del horizonte definido para el experimento. No requiere distribución adicional si se generan las llegadas a partir de los intervalos entre ellas. Depende del horizonte temporal y del proceso de llegadas.
Número de cajeros Cantidad de recursos disponibles para atender a los clientes. Parámetro entero configurable. Cajeros. Escenarios definidos para el experimento de simulación. No aplica; es un parámetro de control. Escenario base: 1 cajero. Escenarios alternativos: 2, 3 o más cajeros, según lo que se desee comparar.

Justificación de las variables nuevas: el tiempo entre llegadas se calcula a partir de las marcas de tiempo del dataset; el número de clientes se deriva del proceso de llegadas; y el número de cajeros es un parámetro de experimentación necesario para responder la pregunta del documento: cómo cambia el tiempo de espera al agregar cajeros.

3. Variables de estado y del proceso

Estas variables permiten representar la evolución del sistema durante la simulación.

Nombre Descripción Tipo Unidad Fuente Distribución utilizada Parámetros
Clientes en fila Cantidad de clientes que esperan a que un cajero quede disponible. Cuantitativa discreta; variable de estado. Clientes. Se calcula durante la simulación a partir de las llegadas y el inicio de atención. No aplica directamente; es el resultado de las reglas del modelo. Estado inicial: 0 clientes, como supuesto de un sistema vacío al inicio.
Cajeros ocupados Cantidad de cajeros que están atendiendo clientes en un instante determinado. Cuantitativa discreta; variable de estado. Cajeros. Estado del recurso en el modelo. No aplica directamente. Entre 0 y el número total de cajeros configurados.
Estado del cliente Indica si el cliente está esperando, en atención o si terminó el proceso. Cualitativa nominal. No aplica. Diagrama de flujo del documento, página 1. No aplica; depende de las reglas de transición del modelo. Estados: espera, atención y salida.
Tiempo de gestión de venta Duración del proceso de escaneo de productos y cobro. Cuantitativa continua en el modelo. Segundos. Variable TranTime del dataset POS. Empírica, reutilizando el tiempo de atención. Valores observados de TranTime. No se debe sumar un tiempo adicional por producto sin evidencia de que ya esté contemplado en esa duración.

4. Variables de salida

Son las medidas que permitirán comparar el desempeño del supermercado cuando se modifica la cantidad de cajeros.

Nombre Descripción Tipo Unidad Fuente Distribución utilizada Parámetros
Clientes atendidos Total de clientes que completan el proceso de pago durante la simulación. Cuantitativa discreta. Clientes. Contador del modelo. No aplica directamente; se obtiene de la ejecución. Conteo acumulado de clientes que finalizan el servicio.
Tiempo promedio de espera Promedio del tiempo transcurrido desde la llegada hasta el inicio de la atención. Cuantitativa continua. Segundos o minutos. Se calcula a partir de las marcas temporales simuladas de llegada e inicio de atención. No requiere una distribución de entrada adicional. W̄q = (1/N) Σi=1N Wq,i, donde Wq,i es el tiempo de espera del cliente i.
Cantidad de clientes en fila Número de clientes que esperan en un instante o promedio de clientes en espera durante la simulación. Cuantitativa discreta. Clientes. Estado de la cola durante la simulación. No aplica directamente. Puede medirse como valor instantáneo o promedio temporal; se debe especificar cuál se reporta.
Tiempo total en el sistema Tiempo que transcurre desde la llegada del cliente hasta su salida. Cuantitativa continua. Segundos o minutos. Se calcula con las marcas temporales simuladas de llegada y salida. No requiere distribución de entrada adicional. Ti = Wq,i + Si, donde Si es el tiempo de atención.
Utilización de los cajeros Proporción del tiempo durante el cual los cajeros permanecen ocupados. Cuantitativa continua. Porcentaje. Tiempos de ocupación y disponibilidad registrados por el modelo. No aplica directamente. U = tiempo total ocupado / (c × tiempo de simulación), donde c es el número de cajeros.

5. Parámetros generales del modelo

Además de las variables, el modelo necesita parámetros que definan las condiciones del experimento.

Parámetro Descripción Valor o criterio de definición Justificación
Número de cajeros (c) Recursos disponibles para atender clientes. 1 para el escenario base; después se comparan 2, 3 y más. Es la variable de decisión principal del problema.
Horizonte de simulación Tiempo total durante el cual se ejecuta el modelo. Debe establecerse antes de ejecutar los experimentos. Permite comparar escenarios bajo una duración común.
Estado inicial Condición de la fila y los cajeros al comenzar. Cola vacía y todos los cajeros libres. Supuesto inicial que facilita la comparación; debe documentarse.
Regla de atención Orden en el que los clientes pasan a caja. Primero en llegar, primero en ser atendido (FIFO). Supuesto operativo razonable para una fila convencional, aunque el documento no especifica expresamente la disciplina.
Número de repeticiones Cantidad de ejecuciones independientes del modelo. Se determina según la variabilidad de los resultados y la precisión deseada. Permite evaluar la variabilidad entre ejecuciones.
Semilla pseudoaleatoria Valor inicial del generador de números aleatorios. Registrar una semilla por ejecución o un esquema reproducible de semillas. Facilita la reproducibilidad y la comparación entre escenarios.

6. Fuentes y supuestos que deben documentarse

Las variables de transacción provienen del dataset POS, mientras que el flujo operativo y el objetivo de comparación provienen del documento Funcionamiento del sistema.

Se deben dejar explícitos los siguientes puntos:

  • El dataset contiene transacciones observadas, no una medición directa de todos los clientes que llegaron y abandonaron el sistema.
  • BeginDateTime registra el comienzo de una transacción; utilizarlo como instante de llegada del cliente requiere comprobar que ambos acontecimientos coinciden.
  • TranTime representa la duración registrada de una transacción. Su correspondencia exacta con el tiempo de servicio debe comprobarse antes de usarlo en el modelo.
  • El número de cajeros, el horizonte de simulación y el estado inicial son decisiones del diseño experimental, no datos observados del dataset.
  • Las distribuciones empíricas propuestas reproducen los valores observados. Las distribuciones teóricas alternativas deben contrastarse antes de seleccionarlas definitivamente.
